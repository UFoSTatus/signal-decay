### Character Voice Technology
- Web Speech API: free, offline, built into all browsers, limited quality
- ElevenLabs Text-to-Dialogue: premium, $5-22/mo, studio quality, 70+ languages
- OpenVoice v2 / Chatterbox: open source, local, good quality, needs setup
- Decision: hybrid approach (Web Speech default + ElevenLabs premium option)

### Premium CSS/UI Techniques
- CSS @property animated borders (conic-gradient rotation)
- Glassmorphism: backdrop-filter blur(24px) saturate(180%)
- SVG filter glow (feGaussianBlur + feMerge shared filter)
- Pure CSS particles (floating dots, no library)
- Film grain (SVG feTurbulence + steps() animation)
- Zoom-to-fit (bounding box calculation + animated camera transition)

## 💡 CREATIVE DECISIONS FROM THIS SESSION

1. **Investigation Board is a GAME** — not just a map. Progress, achievements, unlockables, theory quiz, story mode
2. **Stories are READ-first** — voices are an optional layer on top, not required
3. **Character voices via Web Speech API** — works free/offline as default, ElevenLabs for premium
4. **Board grows dynamically** — admin panel adds entries, zoom-to-fit adapts
5. **Every app links to every other** — no dead ends, seamless navigation
6. **PWA approach** — install once, works offline, feels native, no app store needed
7. **Three hosting options** — GitHub Pages (free/easy), Azure Static Web Apps (free/pro), Azure Blob (cheap)
